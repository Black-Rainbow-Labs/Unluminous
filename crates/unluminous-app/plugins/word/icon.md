# Making this plugin's icon again

`icon.png` (32 by 32) and `icon-128.png` are drawn by a small script rather than generated by an image
model, which is how the HTML and Designer plugins' marks were made too. The mark is a white page with its
top right corner folded over, a blue heading line and four grey lines of text, on a dark navy rounded
tile: a page that has been written on.

The script is `_agent_output/task-2341-word/make_icon.py` in the repository, which is not committed because
that folder is ignored. It uses Pillow, draws at four times the size and scales down with a smooth filter,
and nothing in it is random, so running it again gives the same two files.

```sh
python _agent_output/task-2341-word/make_icon.py crates/unluminous-app/plugins/word
```

The Settings page's icon is not this picture. It is `settings.icon = document`, which `theme::icon::document`
draws in one colour so it follows the window's colours like every other mark there. This picture is the one
the plugins page and the marketplace show, and the one drawn beside a `.docx` in the explorer and on its tab.
