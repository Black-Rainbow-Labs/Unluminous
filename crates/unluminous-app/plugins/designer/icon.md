# Making this plugin's icon again

`icon.png` (32 by 32) and `icon-128.png` are drawn by a small script rather than generated by an image
model, which is how the HTML plugin's mark was made too. The mark is a pen nib over a page frame, on a dark
navy rounded tile: the frame says a design is a page, and the nib says it is being edited.

The script is `_agent_output/task-2254-designer/make_icon.py` in the repository, which is not committed
because that folder is ignored. It uses Pillow, draws at four times the size and scales down with a smooth
filter, and nothing in it is random, so running it again gives the same two files.

```sh
python _agent_output/task-2254-designer/make_icon.py crates/unluminous-app/plugins/designer
```

The rail button is not this picture. It is `pane.icon = design`, which `theme::icon::design` draws in one
colour so it follows the window's colours like every other mark on the rail. This picture is the one the
plugins page and the marketplace show.
