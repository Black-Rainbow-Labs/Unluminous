# Making this plugin's icon again

`icon.png` (32 by 32) and `icon-128.png` are drawn by `icon.py` in this folder, with Pillow:
`python icon.py` writes both beside it.

The mark is a sheet of cells: a cyan outline and grid, with the header row and the first column filled in
magenta. It uses the cyan `#22B8E6` and magenta `#D946EF` the Mermaid, JSON, Database and Realm icons use,
flat, on a transparent background. It is drawn from numbers at 1024 pixels and shrunk, so it reads at 16
pixels, and it is deliberately not Excel's green X, which is Microsoft's mark.
