Unluminous's own window marks in the `material` set, the one a window opens in: the exact shapes `theme::icon` paints, exported by `cargo run -p unluminous-app --example export_icons_svg`. Drawn in `#1E2530` on a 24 point cell with the mark centred on 12,12. In a page, draw them with `UlIcon`, which takes the current text colour; the colour wheel is the one mark with hues of its own.
