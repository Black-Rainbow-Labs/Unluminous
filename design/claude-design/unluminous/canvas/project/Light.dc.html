Working on Unluminous

Read this before changing anything. It records the conventions the code already follows, so that a later change looks like the rest of the code.

What the crates are for

Crate What is in it unluminous-core The editor: buffer, layout, undo unluminous-app The window: drawing, input, fonts unluminous-cli The command line and its catalogue

A change is installed and launched before it is reported. Run pwsh tools/release.ps1 when the work is done.
